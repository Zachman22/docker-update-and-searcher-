### 4. Safe Update Process with Rollback (660 lines)

**Purpose:** Enterprise-grade container update management with automatic backup and rollback

**Capabilities:**
- ✅ Multi-step safe update workflow:
  1. Pre-update backup creation
  2. New image pull from registry
  3. Container graceful stop
  4. Old container rename (with timestamp)
  5. Configuration preservation
  6. Automatic rollback on failure
- ✅ Update detection & comparison:
  - Docker Hub API integration
  - Image digest comparison
  - Tag-based version comparison
  - Release notes fetching
- ✅ Backup & rollback system:
  - JSON-based configuration backup
  - Filesystem-based storage (backups/<container_id>/)
  - Timestamp-based versioning
  - One-click rollback
  - Automatic rollback on update failure
- ✅ Update strategies:
  - **Conservative:** Only stable releases
  - **Moderate:** Stable + RC (default)
  - **Aggressive:** All versions including pre-releases
  - **Custom:** User-defined rules
- ✅ Registry authentication:
  - Basic Auth for private registries
  - Docker Hub support
  - Custom registry detection
- ✅ Batch operations:
  - Update multiple containers
  - Per-container tracking
  - Continue-on-failure option
- ✅ Container management:
  - Excluded containers list
  - Auto-update toggle
  - Schedule configuration (cron expressions)

**Update Workflow:**
```
Check Updates → Backup → Pull Image → Stop Container →
Rename Old → [Create New] → Verify → Success
                                         ↓
                                      Rollback on Failure
```

**Key Methods:**
```cpp
std::optional<UpdateInfo> checkContainerUpdate(container);
bool performUpdate(updateInfo, backupFirst=true);
bool rollbackUpdate(containerId);
bool createBackup(containerId);
std::vector<std::string> listBackups(containerId);
```

**Use Cases:**
- Safely update containers with automatic backup
- Rollback failed updates with one command
- Check for updates across all containers
- Batch update with failure protection
- Authenticate to private registries

## 🎓 Usage Examples

### Network Diagnostics:
```cpp
NetworkDiagnostics diag;

// Test container-to-container connectivity
auto test = diag.testContainerConnectivity("web", "database");
if (test.status == ConnectivityStatus::Success) {
    std::cout << "Containers can communicate!\n";
}

// Check internet access
auto internet = diag.testInternetConnectivity("web");
if (internet.status != ConnectivityStatus::Success) {
    std::cout << "No internet: " << internet.errorMessage << "\n";
}

// Diagnose all issues
auto issues = diag.diagnoseConnectivityIssues("web");
for (const auto& issue : issues) {
    std::cout << issue << "\n";
}
```

### Dependency Resolution:
```cpp
DependencyResolver resolver;

// Analyze dependencies
auto deps = resolver.analyzeDependencies("web");
for (const auto& dep : deps) {
    std::cout << "Depends on: " << dep.targetContainer << "\n";
}

// Calculate startup order
auto order = resolver.calculateStartupOrder();
if (!order.hasCircularDependency) {
    for (const auto& layer : order.layers) {
        std::cout << "Start in parallel: ";
        for (const auto& container : layer) {
            std::cout << container << " ";
        }
        std::cout << "\n";
    }
}

// Auto-resolve dependencies
if (resolver.resolveDependencies("web")) {
    std::cout << "All dependencies resolved!\n";
}
```

### Error Diagnosis:
```cpp
ErrorDiagnostics diag;

// Full system check
auto issues = diag.runFullDiagnostics();
std::cout << "Found " << issues.size() << " issues\n";

// Check specific container
auto containerIssues = diag.diagnoseContainer("web");
for (const auto& issue : containerIssues) {
    std::cout << issue.title << ": " << issue.description << "\n";

    if (issue.autoFixAvailable) {
        std::cout << "Attempting auto-fix...\n";
        if (diag.attemptAutoFix(issue)) {
            std::cout << "Fixed!\n";
        }
    } else {
        std::cout << "Manual fix required:\n";
        for (const auto& step : issue.suggestedFixes) {
            std::cout << "  - " << step << "\n";
        }
    }
}

// Check system health
auto health = diag.checkSystemHealth();
if (health.healthy) {
    std::cout << "All systems operational\n";
} else {
    std::cout << "Issues detected: " << health.message << "\n";
}
```

### Safe Updates:
```cpp
UpdateChecker checker;
checker.setUpdateStrategy(UpdateStrategy::Conservative);

// Check for updates
std::vector<docker::Container> containers = getContainers();
auto updates = checker.checkForUpdates(containers);

std::cout << "Found " << updates.size() << " updates\n";
for (const auto& update : updates) {
    std::cout << update.containerName << ": "
              << update.currentTag << " → " << update.latestTag << "\n";
    std::cout << "Release notes: " << update.releaseNotes << "\n";
}

// Perform safe update (with backup)
if (checker.performUpdate(updates[0], true)) {
    std::cout << "Update successful!\n";
} else {
    std::cout << "Update failed, rolling back...\n";
    checker.rollbackUpdate(updates[0].containerId);
}

// Batch update
if (checker.performBatchUpdate(updates)) {
    std::cout << "All updates successful!\n";
}
```
